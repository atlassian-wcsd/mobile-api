🚀 Usage Instructions

1. Import the main component:

import ServiceHealthOverview from './src/pages/ServiceHealthOverview';

2. Use in your React application:

<ServiceHealthOverview />

3. Configure environment variables:

REACT_APP_API_BASE_URL=https://your-api.com/v1

4. The component will automatically:

  • Check if the metrics service is available
  • Display real metrics if available, or demo data if not
  • Update every 30 seconds automatically
  • Show health status and allow user feedback
