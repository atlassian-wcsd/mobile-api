# Naming Conventions
- Use camelCase for variables and functions.
- Use PascalCase for classes and React components.
- Constants must be in UPPER_SNAKE_CASE.

# Architectural Patterns
- All data access must go through repository classes.
- Controllers should only handle HTTP logic; business logic goes in services.
- Use Dependency Injection for all services.

# Code Efficiency
- Warn if there are nested loops with O(n^2) or worse complexity.
- Flag repeated DB queries inside loops; suggest batching.
- Recommend using async/await instead of callbacks.

# Alternative Approaches
- Suggest splitting functions longer than 30 lines.
- Recommend using built-in array methods (map, filter, reduce) over manual loops.
- For error handling, use custom error classes.
